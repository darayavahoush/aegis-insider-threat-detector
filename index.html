📐 Mathematical Modeling & Enterprise System Architecture
ZERO-TRUST BEHAVIORAL BIOMETRICS

1. Keystroke Dynamics Mathematical Formulation

Keystroke dynamics quantifies habitual neuro-muscular typing cadences through temporal event intervals:

Dwell Time ($T_{dwell}$): $T_{dwell}(k) = t_{keyup}(k) - t_{keydown}(k)$
Flight Time ($T_{flight}$ / Release-to-Press): $T_{flight}(k-1, k) = t_{keydown}(k) - t_{keyup}(k-1)$
Digraph Latency ($T_{digraph}$ / Press-to-Press): $T_{pp}(k-1, k) = t_{keydown}(k) - t_{keydown}(k-1)$
Rhythm Stability ($CV$): $CV = \frac{\sigma_{flight}}{\mu_{flight}}$

2. Normalized Anomaly Distance (Modified Mahalanobis / Z-Score)

For each extracted feature $x_i$, deviation from the enrolled baseline template ($\mu_i, \sigma_i$) is computed:

$$Z_i = \frac{|x_i - \mu_{base, i}|}{\sigma_{base, i} + \epsilon}$$
$$Z_{composite} = w_d Z_{dwell} + w_f Z_{flight} + w_{cv} Z_{rhythm} + w_{dg} \frac{1}{|D|}\sum_{(i,j)\in D} Z_{dg}(i,j)$$
$$\text{Anomaly Probability } A_{ksd} = 1 - \exp\left(-\frac{1}{2} Z_{composite}\right)$$

3. Acoustic Signal DSP & Voice Biometrics

Using real-time browser Web Audio API FFT analysis, vocal cords and vocal tract physical characteristics are estimated:

Fundamental Pitch ($F_0$ Autocorrelation): $R_{xx}(\tau) = \sum_{n} x[n] x[n+\tau] \implies F_0 = \frac{f_s}{\tau_{max}}$
Spectral Centroid (Timbre Brightness): $\text{Centroid} = \frac{\sum_{k} f_k \cdot |X[k]|}{\sum_{k} |X[k]|}$
Zero-Crossing Rate (ZCR): $\text{ZCR} = \frac{1}{2N} \sum_{n=1}^{N} |\text{sgn}(x[n]) - \text{sgn}(x[n-1])|$

4. Multi-Modal Risk Fusion & MITRE ATT&CK Matrix

The threat engine synthesizes all modalities into an authoritative threat risk index:

$$Risk(t) = \alpha \cdot A_{keystroke} + \beta \cdot A_{voice} + \gamma \cdot A_{mouseContext}$$ $$\text{Thresholds: } <25\% \implies \text{TRUSTED}, \; 25-50\% \implies \text{DRIFT}, \; 50-75\% \implies \text{STEP-UP MFA}, \; >75\% \implies \text{QUARANTINE}$$

5. Privacy By Design (GDPR / Zero Keylogging Compliance)

Traditional keyloggers violate corporate privacy by recording characters typed. Aegis employs differential timing abstraction: it discards the text and only aggregates timing deltas, digraph durations, and non-reversible acoustic features. Even if telemetry is intercepted, the underlying passwords or confidential documents cannot be reconstructed.
